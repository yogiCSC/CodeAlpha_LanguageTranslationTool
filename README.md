# 🌍 Language Translation Tool

This project was developed as part of the **CodeAlpha Artificial Intelligence Internship**.

The Language Translation Tool allows users to translate text between multiple languages using Python and Streamlit.

---

## 🚀 Features

- Translate text instantly
- Multiple language support
- Simple and interactive user interface
- Fast and accurate translation

---

## 🛠 Technologies Used

- Python
- Streamlit
- deep-translator

## ▶️ How to Run the Project

### Step 1: Install Required Libraries

```bash
pip install -r requirements.txt
```

### Step 2: Run the Application

```bash
python -m streamlit run app.py
```
